# Persian RSVP Speed Reader

سامانه تندخوانی فارسی بر پایه معماری **Smart Backend + Dumb Player** به روش RSVP (Rapid Serial Visual Presentation) به همراه موتور هوشمند زبانی، پایگاه‌داده با **Tortoise ORM** و سیستم احراز هویت امن با **JWT**.

این سامانه به گونه‌ای طراحی شده است که تمام منطق هوشمند و تجاری (پردازش زبان طبیعی فارسی، توکنایزیشن، نیم‌فاصله‌ها، مکث‌های شناختی و محاسبه نقطه تمرکز ORP) در سمت سرور در یک ماژول مجزا نگهداری می‌شود و مرورگر/اکستنشن تنها نقش یک پخش‌کننده سریع (۶۰ فریم در ثانیه با بافرینگ و Prefetch چندمرحله‌ای) را ایفا می‌کند.

---

## قابلیت‌های کلیدی

1. **موتور هوشمند RSVP فارسی (Backend Intelligence):**
   * نرمال‌سازی پیشرفته خط فارسی (حذف کشیده، اعراب و نویسه‌های مخفی bidi، تبدیل ارقام عربی-مشرقی).
   * توکنایزیشن آگاه از نیم‌فاصله (`U+200C`) و اتصال وندها و کلمات مرکب (مانند «می‌خواهم»، «کتاب‌خانه»).
   * محاسبه دقیق نقطه کانونی ORP روی بدنه اصلی کلمه مستقل از علائم نگارشی.
   * زمان‌بندی شناختی تطبیقی با تولید وزن‌های مات و غیرقابل مهندسی معکوس (`d`).
   * تکه‌بندی (Chunking) و پیش‌دریافت (Prefetching) خودکار بدون وابستگی به شبکه برای تک‌تک کلمات.
2. **پخش‌کننده کارآمد و مستقل کلاینت (Dumb Player):**
   * بدون هیچ‌گونه کد یا فرمول اختصاصی در جاوااسکریپت کلاینت.
   * رندرینگ روان بدون پرش (Zero Jitter) با جبران رانش زمانی (Drift-Compensated Timer) برای سرعت‌های تا ۱۰۰۰ WPM.
   * کشینگ متریک‌های رندرینگ برای پیشگیری از Layout Thrashing و افت فریم.
   * بازیابی هوشمند با الگوریتم Exponential Backoff در هنگام خالی شدن بافر (Buffer Underrun).
3. **احراز هویت و امنیت (Authentication & Security):**
   * رمزنگاری امن گذرواژه‌ها با الگوریتم **Bcrypt** (محدود به ۷۲ بایت مطابق استاندارد).
   * تولید و اعتبارسنجی توکن‌های استاندارد **JWT (JSON Web Tokens)**.
   * ثبت‌نام، ورود، و دریافت اطلاعات پروفایل به همراه حفظ سشن در `localStorage`.
4. **پایگاه‌داده و مدیریت متون (Database & Library):**
   * پیاده‌سازی شده با **Tortoise ORM** (مدل‌های `User` و `SavedText`).
   * ذخیره سرعت مطالعه دلخواه (`preferred_wpm`) برای هر کاربر.
   * قابلیت از سرگیری مطالعه از هر نقطه دلخواه در متن‌های طولانی چندتکه‌ای.

## ساختار پروژه

```text
persian-rsvp/
├── app.py                      # سرور اصلی FastAPI، ثبت روت‌ها و ارتباط با دیتابیس
├── config.py                   # تنظیمات برنامه، مسیر دیتابیس و اعتبارسنجی محیط تولید
├── database.py                 # تنظیمات پیکربندی Tortoise ORM
├── models.py                   # مدل‌های دیتابیس (User و SavedText)
├── schemas.py                  # اسکیماهای اعتبارسنجی ورودی/خروجی با سقف طول متن
├── auth.py                     # توابع هش رمز (bcrypt) و ایجاد/بررسی توکن JWT
├── rsvp_engine/                # موتور اختصاصی و هسته هوشمند RSVP
│   ├── __init__.py             # اکسپورت‌های پکیج موتور
│   ├── models.py               # مدل‌های داخلی توکن، اسکیماهای خروجی و نسخه موتور (engine_version)
│   ├── normalization.py        # نرمال‌سازی کاراکترها، ارقام، اعراب و علائم مخفی
│   ├── tokenizer.py            # توکنایزیشن زبانی فارسی با حفظ پیوستگی
│   ├── orp.py                  # محاسبه نقطه کانونی با حذف خطای علائم نگارشی
│   ├── pacing.py               # محاسبه وزن‌های شناختی مات مدت‌زمان نمایش
│   ├── chunking.py             # تکه‌بندی داده‌ها برای بافرینگ کلاینت
│   └── engine.py               # نمای هماهنگ‌کننده (Facade) پایپ‌لاین موتور
├── routers/
│   ├── auth.py                 # اندپوینت‌های ثبت‌نام، لاگین و دریافت اطلاعات کاربر
│   ├── rsvp.py                 # اندپوینت دریافت پلن و تکه‌های توکن (/api/rsvp/plan)
│   └── texts.py                # اندپوینت‌های CRUD کتابخانه و متون ذخیره‌شده
├── templates/
│   └── index.html              # ساختار تک‌صفحه‌ای UI و فراخوانی ماژولار اسکریپت‌ها
├── static/
│   ├── style.css               # استایل‌های تم دارک، کامپوننت‌های مدرن و واکنش‌گرا
│   ├── app.js                  # منطق رابط کاربری و اتصال رویدادها به پلیر
│   └── rsvp/                   # ماژول‌های پخش‌کننده کلاینت (Dumb Player)
│       ├── api.js              # کلاینت ارسال و دریافت تکه‌های توکن
│       ├── buffer.js           # مدیریت صف بافر و موقعیت مطلق متون
│       ├── renderer.js         # رندرینگ با Range API، تراز فیزیکی و کش متریک‌ها
│       ├── timer.js            # تایمر با جبران رانش زمانی (Drift Compensation)
│       └── player.js           # کنترل‌کننده جامع پلیر با مدیریت خطا و Prefetch
├── requirements.txt            # لیست وابستگی‌ها و پکیج‌های پایتون و تست
├── test_api.py                 # تست‌های خودکار مجزا با دیتابیس ایزوله تستی
├── RSVP_ENGINE_DEVELOPMENT_PLAN.md # سند جامع نقشه راه و وضعیت فازها
└── README.md
```

## راه‌اندازی و اجرا

```bash
# ۱. نصب وابستگی‌ها
pip install -r requirements.txt

# ۲. اجرای سرور
python app.py
```

سپس در مرورگر خود باز کنید:
**[http://127.0.0.1:8000](http://127.0.0.1:8000)**

مستندات تعاملی Swagger API:
**[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)**

## اجرای تست‌ها

تست‌ها در محیطی کاملاً ایزوله (با فایل دیتابیس مجزا) اجرا شده و دیتابیس اصلی برنامه دست‌نخورده باقی می‌ماند:

```bash
pytest -v
# یا
python test_api.py
```

## کنترل‌های صفحه و کلیدهای میانبر

* **کلید Space:** توقف / ادامه مطالعه (Pause / Resume)
* **کلیدهای ↑ و ↓:** افزایش یا کاهش سرعت (هر بار ۱۰ WPM)
* **کلید R:** بازنشانی خواندن (Reset)
